# GroupPings_CapstoneF3
CSIT 227 Capstone from the GroupPings group

This Capstone Repository is for the unnamed Donor-Receiver app that aims to help social welfare institutions by allowing them to easily accept donations from donors who have a surplus of food that otherwise goes to waste. 

Main features: 
- Simple food listing for institutions.
- Simple food ordering process.
- Safety checks for food.
- Simple delivery handling.

Nov/16/2026

How the user will navigate the interface:
1. Login/Create account
2. Choose whether the user is a supplier or recipient.
   Suppliers - are the ones to provide leftover food. These are institutions such as Bakeries, and Restaurants.
   Recipients - are the ones that receive the provided food. These are institutions such as Orphanages and Nursing Homes.
3. Inside the Supplier interface the user is able to:
     a. List up food items they can provide.
     b. View their listed food items.
     c. Check active deliveries of claimed food.
   Inside the Recipient interface the user is able to:
     a. View listed food items from different suppliers.
     b. Check active deliveries they have claimed.
