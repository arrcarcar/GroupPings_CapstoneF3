# Pay It Forkward

*Good food deserves a second plate.*

CSIT 227 Capstone from the GroupPings group.

Pay It Forkward is a Java Swing app that connects food suppliers (bakeries, restaurants, supermarkets) with the social welfare institutions that can use their surplus (orphanages, nursing homes, homeless shelters), so edible food gets eaten instead of thrown away.

## Main features

- Simple food listing for suppliers.
- Simple food claiming for recipients.
- Safety checks for food (perishable and non-perishable rules).
- Simple delivery handling with volunteers.

## How the user navigates

1. Choose whether the user is a Supplier or a Recipient.
2. Select the establishment.
3. Supplier dashboard:
   - **Donor Portal**: list surplus food.
   - **Pantry Dispatch Feed**: view listed food, sorted by urgency or by volume, and claim a batch.
   - **Active Deliveries**: assign a volunteer and mark a batch as delivered.
4. Recipient home: view listed food and claim items.

Login / Create account is planned and not yet implemented.
