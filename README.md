# GroupPings_CapstoneF3
CSIT 227 Capstone from the GroupPings group

This Capstone Repository is for the unnamed Donor-Receiver app that aims to help social welfare institutions by allowing them to easily accept donations from donors who have a surplus of food that otherwise goes to waste. 

Main features: 
- Simple food listing for institutions.
- Simple food ordering process.
- Safety checks for food.
- Simple delivery handling.
