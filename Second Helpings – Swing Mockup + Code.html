Second Helpings – Swing interface mockup + code

Functionality first. Click through the windows exactly as the Java app will behave.

Sample accounts in the mock: supplier1 / pass123 or recipient1 / pass123. Try adding a blank name or quantity 0 to see the custom exception popup.



Setup: IntelliJ → New Project (Java, JDK 17+) → paste each file into src/ (default package). Run Main. The GUI is built in code, so no .form files are needed. Data saves to inventory_data.txt in the project folder.
